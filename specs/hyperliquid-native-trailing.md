# Specification
Plan gains trailing_provider=local|native (default local); native restricted to catalogued Hyperliquid perps. Local policy unchanged. Native management freezes ATR quote distance, activation immediately; fixed entry SL retained independently. Low-level method supports protective buy/sell, quote or percent retracement, optional activation; always reduceOnly. Reject nonfinite/invalid values, unsupported assets, stale verification, invalid precision, missing credentials and invalid environment before signed I/O.
Persist a trailing attempt before a single transmission after terminal entry and verified full fixed-SL coverage. Read trailing only by acknowledged native oid. Missing oid is unknown and blocks automatic resubmission/adoption. Strict readback matches coin, oid, side, reduceOnly, type, requested retracement and valid best mark; unknown formats fail closed. An acknowledgement alone never counts as coverage. A previously accepted terminal native trail latches exit of remaining exposure. A rejected submission is not an established watermark. Restart never resets exchange watermark. Ordinary reduction may leave oversized reduce-only protection; flat cleanup cancels both stop kinds and requires terminal readback.
No schema migration: plan/attempt/position snapshots already JSON. Diagnostics expose separate trailing coverage and provider. Existing plans with no selector remain local. Rollback: preserve existing managed records, do not silently switch active policy. Operator reconciles and closes native positions before reverting code.

## Corrective contract
- Normalize frozen ATR quote distance using metadata decimal precision and the distance's own significant figures (integers remain allowed). Persist it on the managed row before any entry. Reject zero normalization before entry. Existing in-flight records without the field calculate it from current metadata before their first trail, without resending existing attempts.
- No oid or rejected trailing submission: INTERVENTION, no automatic retry/adoption, retain and monitor fixed SL. This specific intervention may still process explicit exit requests, fixed-SL loss and cleanup; unrelated reconciliation failures remain frozen.
- Verified open full-sized waiting order (best waiting or missing best): zero active trailing coverage, remain PROTECTING, no timeout exit solely for waiting. Continue normal fixed-SL and terminal-order handling; active readback moves to PROTECTED, including after restart.
- Parse retracement (quote/percent), optional activation above/below and optional best independently. Reject duplicate, unknown, nonfinite and malformed clauses. Managed readback accepts only the requested quote distance and immediate activation; percentage or explicit activation remains a semantic mismatch, not a grammar error.

Clarification: rejection of a submission without an acknowledged order ID is distinct from a later rejected status on an accepted known-ID trail. The latter is terminal and retains residual-exit handling.
