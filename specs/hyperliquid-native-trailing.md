# Specification
Plan gains trailing_provider=local|native (default local); native restricted to catalogued Hyperliquid perps. Local policy unchanged. Native management freezes ATR quote distance, activation immediately; fixed entry SL retained independently. Low-level method supports protective buy/sell, quote or percent retracement, optional activation; always reduceOnly. Reject nonfinite/invalid values, unsupported assets, stale verification, invalid precision, missing credentials and invalid environment before signed I/O.
Persist a trailing attempt before a single transmission after terminal entry and verified full fixed-SL coverage. Read trailing only by acknowledged native oid. Missing oid is unknown and blocks automatic resubmission/adoption. Strict readback matches coin, oid, side, reduceOnly, type, requested retracement and valid best mark; unknown formats fail closed. An acknowledgement alone never counts as coverage. A known terminal native trail latches exit of remaining exposure. Restart never resets exchange watermark. Ordinary reduction may leave oversized reduce-only protection; flat cleanup cancels both stop kinds and requires terminal readback.
No schema migration: plan/attempt/position snapshots already JSON. Diagnostics expose separate trailing coverage and provider. Existing plans with no selector remain local. Rollback: preserve existing managed records, do not silently switch active policy. Operator reconciles and closes native positions before reverting code.
